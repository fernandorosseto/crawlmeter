# Code of Conduct

crawlmeter follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and keep discussion about the work. Harassment, personal attacks and discriminatory language are not accepted in issues, pull requests, discussions, or any other project space.

## Reporting

To report a problem, use the repository's private reporting form at https://github.com/fernandorosseto/crawlmeter/security/advisories/new and say in the title that it is a conduct report. Only the maintainers can see it. Do not open a public issue for it. Reports are handled confidentially.

The maintainers will review each report and respond in a way they judge appropriate, as described in the Contributor Covenant's enforcement guidelines.
